# Schemas

Versioned machine-readable UMCGS contracts and metaschemas live here.

Schemas are authoritative sources for generated bindings, layouts, validation, and compatibility where an accepted specification says so. Generated consumers do not become independent sources of truth.

## Accepted schemas

- [`search-ir/0.1.0/search-ir.schema.json`](search-ir/0.1.0/search-ir.schema.json) — closed structural schema for the CUDA-MCGS Search IR accepted by SPEC-0002; cross-field requirements remain owned by its normative normalizer.

Planned families include domain, policy, evaluator, resource/memory plan, graph semantics, output, component manifest, device-module ABI, and specialization cache identity.
