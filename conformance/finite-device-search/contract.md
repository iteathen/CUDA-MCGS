# Selected finite Device-JS core contract

`createFiniteDeviceSearchCore(context, {name,maxIterations,maxActions?,externalParameters?,frontierParticipation?})` is a public `cuda-mcgs/search-compiler` pre-ignition port. Context contains accepted authority and normalized Domain, Graph, Policy, Resource, Progress and Output results, identity-matching Domain/Policy source bundles, and exact typed owner-port references. There are no active JS callbacks.

The selected Graph is materialized, verified-sharing and no-reclamation. The selected Policy deletes Evaluator and must supply terminal/frontier/cycle/depth meaning. Domain state/action/outcome max encoded extents must be exact multiples of four bytes. Exactly one 32-bit integer and one 32-bit floating record family per node/edge is selected. Counters never use f32. Resource/Progress/Output identity and finite byte/work bounds are consumed and checked. No caller chooses physical offsets.

`source` and five `functions` form a device-only module. The final function is the core callable. `programContributions` splits the Graph helpers from the Progress traversal callable with source identities, typed canonical Composer functions, exact call/helper sets, and launch constraint. The caller closes Graph/Progress source identities and dependent owner references through the ordinary normalizers/Composer. Generator source bytes do not depend on owner identity hashes, so this source-identity closure is deterministic. `buffers` supplies eight exclusive, disjoint, exact finite extents; resource allocation and operation bindings belong to Resource/Composer/runtime owners. `callbackBufferRanges` supplies callback record/view extents in elements. External parameters must be typed pointer capabilities owned by a selected Resource contributor and cannot shadow generated locals.

Parameters, in order: metadata `m:u32[]`, states `s:u32[]`, actions `a:u32[]`, Policy integers `p:u32[]`, Policy numeric records `f:f32[]`, Graph scratch `su:u32[]`, Policy scratch `sf:f32[]`, bounded output `out:u32[]`, cancellation `sideband<host-to-device,u32>`, expected arena, root generation, focus epoch, then explicit external capabilities. Fresh buffers are zero initialized except metadata arena at word10, immutable focus epoch at11, optional bounded work nonce at2, and admitted root state at `s[0]`. All selected buffers and callback dependencies remain exclusively owned for the entire operation. Buffers retain resident graph state until arena teardown. This profile allows one invocation per finite operation, rejects reentry, and has no live root/focus switch or continuation claim.

Frontier metadata must explicitly declare `{kind:'controller-only',blockSize:1}` and grid/block `['1','1','1']`. A missing declaration or collective callback fails cold. A later collective profile must provide uniform producer/barrier/all-participant-callback/barrier/controller-commit stages and a distinct selected identity; invoking collective callbacks in the controller branch is forbidden.

`layout` records every offset and capacity. Metadata has 32 control words, eight words per node and edge, and five words per protected path occurrence. Node generation and edge generation are one in this no-reclamation profile; arena incarnation and reference generation are validated. State identity is Domain key followed by full Domain equality. Expansion stages every action and destination, verifies uniqueness and validity, and checks complete capacity before publishing any new node/edge. Parent edges keep separate Policy records on shared children.

Controls: 0/1 node/edge count, 2 work nonce, 3 completed, 4 abandoned, 6 stop, 7 phase, 8 root slot, 9 active work, 10 arena, 11 focus, 12 last committed work, 13 backup phase (1 committing,2 complete,3 quarantine), 14 transitions, 15 expansions, 16/17 work leases claimed/released, 18/19 edge reservations/released, 20 selections, 21 verified transposition hits, 23 active path count, 26 quarantined work count, 30 raw Domain failure. Node words are publication, generation, key, head edge, edge count, expanded, protection count and reserved. Edge words are publication, parent, parent generation, child, child generation, next edge, reserved and generation. Path words are node, node generation, incoming edge, edge generation and work nonce.

Output copies the 32 control facts, replacing word0 with stop, word24 with valid-action flag, word25 with selected edge, and words32 onward with one generic action. Read-only decision hooks receive copied candidate owner-record views. Stop codes: 1 finite bound,2 cancelled,3 node pressure,4 edge pressure,5 path pressure,6 stale reference/focus,7 Domain invalid/failure,8 Policy failure,9 nonterminal without actions,10 counter exhaustion,11 quarantined irreversible backup. Policy frontier returns 0 value ready,1 continue,other failure; terminal reports0 nonterminal,1 terminal,other Domain failure. Frontier reasons0 ordinary,1 path relation,2 depth bound never imply an implicit value.

Each work owns one leaf/work lease and protected path. Reservation/preparation failure or precommit cancellation abandons with no backup. After the first irreversible backup step, cancellation drains the full admitted backup before release; failure quarantines the work and suppresses root decision. Every incoming edge reservation and node protection is released once. No host loop, search fallback, reclamation, value formula or game vocabulary is generated.
