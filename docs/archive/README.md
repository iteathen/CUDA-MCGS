# Documentation Archive

**Status:** Informational

Historically useful stale or superseded material is retained with provenance rather than silently deleted.

An archive record states original path, archive date/path, source revision, reason, superseding authority, and supersession/removal commit. Generated junk, accidental uncommitted duplicates, secrets, or unsafe material may be deleted with the reason recorded in the change description.

Archived material is evidence of history, not current authority.
