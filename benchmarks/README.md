# Benchmarks

Cross-component and system-level reproducible performance suites live here.

Each benchmark records exact commit/generated-engine identity, hardware/software profile, model/evaluator, resource profile, workload, timing/synchronization boundary, raw results, correctness/quality guardrails, and profiler evidence.

Component-local microbenchmarks remain with their owning component.

Do not commit uncontrolled bulk result output. Store only curated baselines or schemas when repository retention is justified.
